📥 How to Use in Unity

  • Import Models: Drag all .obj files from Assets/Docs/LittleCafe/Models/ into Unity. They'll appear in your Project panel.
  • Create Materials: Create unlit materials with solid colors:
    → Right-click in Project → Create → Material
    → Set Shader to "Unlit/Color"
    → Set colors from specs above
  • Assign Materials: Drag each .obj into Scene, then drag the matching material onto the model in the Inspector.
  • Create Prefabs: Drag the models from Hierarchy into Assets/LittleCafe/Prefabs/Equipment/ to create prefabs.
  • Scale Check: Models are designed for 1x1 grid units. Verify they align with your GridManager tiles.
  • Replace Cubes: Update your Equipment classes to use these prefabs instead of procedural cubes.
