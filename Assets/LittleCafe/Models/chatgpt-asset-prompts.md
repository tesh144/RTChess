Use these prompts one at a time with ChatGPT (DALL-E) to generate reference images for 3D modeling.

**IMPORTANT STYLE REFERENCE**: All assets should match the visual style of **Overcooked** and **Plate Up** - isometric low-poly 3D assets with soft rounded edges, warm inviting colors, clean readable shapes, and cozy restaurant sim aesthetic. Assets should look functional, cute, and slightly cartoony without being overly stylized.

## USAGE INSTRUCTIONS

### How to Use These Prompts:

1. **Copy one prompt at a time** into ChatGPT (with DALL-E access)
2. **Review the generated image** - it should show 3 orthographic views (front, side, top)
3. **Save the image** to your reference folder with a clear name (e.g., "counter_reference.png")
4. **Import into your 3D software** (Blender recommended) as reference images
5. **Model the asset** using the orthographic views as guides:
   - Set up reference images in front/side/top viewports
   - Model to match the exact proportions and shapes shown
   - Keep polygon count low (under 500 polys per asset)
   - Use smooth shading with edge creases for crisp edges
6. **Apply materials** using the hex colors specified in each prompt
7. **Export as .obj** files with proper scale (1 unit = 1 meter)
8. **Import to Unity** at `Assets/LittleCafe/Models/`

### Important Notes:

- **Reference the included screenshots** from Overcooked and Plate Up for style accuracy
- All assets must use **rounded edges**, not sharp corners (0.02-0.05 unit bevel radius)
- Keep the **cozy, approachable aesthetic** - nothing should look intimidating or harsh
- Assets should be **immediately readable** from an isometric camera angle
- Use **simple geometry** - remember these are background props, not hero assets
- Colors should be **vibrant but not neon** - warm and inviting
- Each asset must fit the **1×1 grid system** (except pot and bin which are smaller)

### Quality Check:

Before finalizing each model, verify:
- [ ] Matches orthographic views from ChatGPT reference
- [ ] Has rounded edges (no sharp corners)
- [ ] Uses correct colors from hex codes
- [ ] Fits on 1×1 grid (or correct smaller size)
- [ ] Looks good from 45-degree isometric view
- [ ] Has appropriate level of detail (not too simple, not too complex)
- [ ] Matches Overcooked/Plate Up visual style
